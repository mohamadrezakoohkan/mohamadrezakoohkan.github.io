Welcome to my new personal blog! I decided to build this entirely from scratch using **pure HTML, CSS, and Vanilla JavaScript**. No heavy frameworks, no complex build steps, just the fundamentals of the web.

## Why Vanilla Web Tech?

Sometimes, simplicity is the ultimate sophistication. By avoiding massive libraries, I get a site that is:

1. Blazing fast to load.
2. Easy to maintain.
3. Hosted for free on GitHub Pages.

### A Little Code Snippet

Here is a look at how simple things can be:

```javascript
function greetWorld() {
  console.log("Hello from a lightweight blog!");
}
greetWorld();
```
